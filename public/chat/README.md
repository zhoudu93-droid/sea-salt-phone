# 山茶信笺 · Camellia Chat

一个只住在你手机里的小世界。

打开就是一台属于你自己的微信：自己注册账号、自己添加人设、自己发朋友圈、自己管钱包。
所有数据只存在本机浏览器里，不上传任何服务器。

---

## 一、怎么用

### 1. 创建账号
首次打开会进入注册页：填头像、昵称、微信号（自动生成，可改）、个性签名。
填完点「创建账号并进入」即可。

### 2. 添加人设
进入后底部有四个标签：**微信 / 通讯录 / 朋友圈 / 我**。

- 到【通讯录】→「添加人设」，开始创建一个人物：
  - **头像 / 名字 / 备注 / 微信号 / 个性签名**：外观信息
  - **人设 · 他是谁**：他的性格、身份、说话方式。写得越具体，他越像他。
  - **开场白**：第一次打开对话时他会先说这句话（留空则等你先开口）
  - **专属模型**：只给这个人用的模型名（留空则用桌面设置里的主 API）
  - **温度**：0 到 2。低一点更稳，高一点更活。

系统第一次会内置一张**空白人设**，直接点它右边的编辑改成你想要的人就行。

### 3. 聊天
- 在【通讯录】点任意人 → 名片页 → 「发消息」
- 输入框左下角 `＋` 打开抽屉：**表情 / 图片 / 转账 / 拍一拍**
- 长按右上角 `⋯` 可以查看名片、清空对话、编辑人设

### 4. 朋友圈
- 右上角相机图标发一条（可带图）
- 也可以选「以某人的身份发一条」—— 人设会自己写
- 或者点人设的名字，让他自己发一条真实的日常
- 可以点赞、评论

### 5. 钱包
【我】→ 钱包：存入 / 取出 / 零钱明细。
聊天里给对方转账会真实扣减零钱余额。

### 6. 表情包
【我】→ 表情包：把相册里的任何一张图加进来，它就会出现在聊天抽屉里。

## 二、接口配置（重要）

**微聊内部没有任何 API 设置入口。**

大模型接口统一在小手机桌面的 **设置中心** 里维护，微聊只负责读取。

填写四个位置即可：

| 位置 | 存储键 | 说明 |
|---|---|---|
| 主 API 地址 | `sea_salt_api_url` | 例如 `https://api.deepseek.com/v1` |
| 主 API 密钥 | `sea_salt_api_key` | `sk-...` |
| 主 API 模型 | `sea_salt_api_model` | 例如 `deepseek-chat` |
| 副 API 地址 | `sea_salt_api_url_b` | 备用线路 |
| 副 API 密钥 | `sea_salt_api_key_b` | |
| 副 API 模型 | `sea_salt_api_model_b` | |

**主 API 失败时自动切到副 API**，两条都填就等于多一层保障。
任何一条填完整就能用。

【我】→ 接口状态 可以随时看到主 / 副是否就绪（只读，不能在这里改）。

## 三、对话引擎说明

### 短气泡连发
模型每输出一行，就会被切成一条独立的消息气泡，一条条弹出来。
这就是「活人感」的来源——真人不会一次发一大段。

### 活人感底座（内置）
每次请求都会自动注入一段行为规范，核心是：

- 每条消息都是拇指敲出来的，想到什么发什么，一两句就够
- 用换行分条，系统会拆成多条消息
- 句尾通常不打句号；句号是冷淡、赌气的信号
- 大部分时候只是陈述，不连续追问
- **禁止一切括号 / 中括号 / 书名号 / 破折号 / 引号来写动作神态旁白**
- 禁止说教、禁止总结、禁止镜像复读对方的话
- 要记得对方说过的事，要有自己的生活，要会主动，也会安静

### 拆条机制
L1 · 行内换行 → 拆成多条气泡（每条间隔 380ms 依次弹出）

## 四、部署

### 方式一：直接放
把整个 `sea_salt_chat` 文件夹丢到任意静态托管（Netlify / Cloudflare Pages / Vercel），
入口 `index.html` 即可。已附带 `_redirects`。

### 方式二：装进小手机
放进小手机目录的 `chat/` 子文件夹，
小手机桌面点【山茶信笺】就会进入微聊。
因为同源，两边的 localStorage 共享 —— 设置中心填的 API 微聊直接能读到。

### 方式三：装到 iOS 主屏
Safari 打开 → 分享 → 添加到主屏幕。
manifest 与图标已配好，会以独立 App 形态全屏运行。

## 六、数据存放

全部在 `localStorage`，键名前缀 `pchat_`：

| 键 | 内容 |
|---|---|
| `pchat_account_v1` | 你的账号资料 |
| `pchat_personas_v1` | 所有人设 |
| `pchat_chats_v1` | 所有聊天记录 |
| `pchat_moments_v1` | 朋友圈 |
| `pchat_wallet_v1` | 钱包与流水 |
| `pchat_stickers_v1` | 自定义表情包 |
| `pchat_prefs_v1` | 主题等偏好 |

换手机、清缓存前记得先备份。
